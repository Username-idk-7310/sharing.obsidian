> [!yellow] # Multi-Store Model (MSM)

## Sensory buffer/register/environmental input  
- temporary store
- large cap + short duration
- holds envir info (visual, audiotory, tactile, olfactory)
- needs attention to be transferred to LTM

## Short-term memory (STM)
- limited cap + duration
- info enters STM from sensory buffer if attention is paid to stimuli 
- info enters LTM from ST thru rehearsal
