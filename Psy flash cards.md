# <span style="color:rgb(203, 148, 60)">Causality </span>
- strong causal claims need high ctrl, but behvr is complex
- psychologists balance between experimental validity (internal) and real-world relevance (external)

| Key idea                        | definition                                                                                                                                        |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| Correlation vs causation        | association doesn't necessarily prove cause                                                                                                       |
| Bidirectional ambiguity         | does X cause Y, or does Y cause X?                                                                                                                |
| Internal validity               | to what extent does IV effect DV?                                                                                                                 |
| External validity               | to what extent can the findings be generalized?                                                                                                   |
| Controls + extraneous variables | reduce alt explanations                                                                                                                           |
| Double-blind                    | limits participant + researcher bias                                                                                                              |
| Placebo                         | limits participant + researcher bias                                                                                                              |
| Complexity                      | behvr usually has many interacting causes                                                                                                         |
| Agency                          | individuals also make choices that are not determined by variables                                                                                |
| Determinism                     | argues behvr is shaped by genetic/envir factors outside of indivisual's ctrl. over-reliance on deterministic models can undermine personal agency |

| Key term                  | definitions                                                                                   |
